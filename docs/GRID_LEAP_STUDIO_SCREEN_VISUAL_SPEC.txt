1. BRAND TYPOGRAPHY & DESIGN HARMONY
--------------------------------------------------------------------------------

• Studio Brand Typography:
  - Primary: `'Bodoni Moda', serif` — Consistent with your studio's brand trademark
    across all games, featuring high-contrast vertical stems and hairline serifs.
  - Sizing: `64px` for "OLAI", `32px` for "DIGITAL STUDIOS", with precise optical
    trailing margin compensation (`-0.12em` / `-0.1em`) for true geometric centering.
  - Subtitle Notice: `'JetBrains Mono', monospace` (`11px`, `0.3em` letter-spacing,
    lowercase `presents`).

• Grid Leap Aesthetic Harmonization:
  - Dual Themes: Automatically binds to Grid Leap's Obsidian (Deep Cosmic Void #121316)
    and Vellum (Warm 300gsm Debossed Cream Paper #F7F5F0) color spaces.
  - Background: Renders Grid Leap's signature 28px Cartesian coordinate grid, so the
    dissolve into the Home Hub is 100% continuous and seamless.
  - Optional Reticle Accents: Four delicate L-shaped corner brackets (┌ ┐ / └ ┘) softly
    frame the studio logotype with tactile architectural elegance.

4. ELEMENT-BY-ELEMENT VISUAL SPECIFICATIONS
--------------------------------------------------------------------------------

A. Fullscreen Overlay (`#startupOverlay.startup-overlay`):
   - Position: `fixed`, `inset: 0`
   - Z-Index: `9999`
   - Background: `var(--studio-bg)` with 28px Cartesian grid pattern
   - Display: `flex`, `align-items: center`, `justify-content: center`
   - Transition: `opacity 0.7s cubic-bezier(0.2, 0, 0, 1), visibility 0.7s ease`
   - Initial State: `opacity: 1; visibility: visible;`
   - Touch Action: `none`

B. Architectural Reticle Frame (`.startup-reticle-frame`):
   - Position: `relative`
   - Width: `clamp(280px, 80vw, 440px)`
   - Height: `clamp(230px, 40vh, 320px)`
   - Display: `flex`, `align-items: center`, `justify-content: center`

   - Size: `16px` width, `16px` height

--------------------------------------------------------------------------------
5. TIMINGS & INTERACTION BEHAVIOR
--------------------------------------------------------------------------------

• Display Duration:
  - Default: Stays on screen for `2500ms` (2.5 seconds).
  - Tap / Click: Tap anywhere on screen immediately dismisses intro (instant skip).
  
• Fade-Out Transition:
  - Slide scales subtly (`scale(0.96)`) and fades (`500ms`).
  - Overlay container fades to `opacity: 0` (`700ms cubic-bezier(0.2, 0, 0, 1)`).
  - DOM Cleanup: `overlay.remove()` completely cleans up memory after completion.
  - Lifecycle: Fires `onComplete()` callback, transitioning cleanly into Home Hub.

• Multi-Platform Behavior:
  - Production Targets (`playstore`, `itch`, `web`, `desktop`): Displays on initial application launch.
  - Editor Target (`editor`): Instant or fast-skipped so developer workflow remains rapid.
